# FFmpeg Build Script (Cross-Platform & Extreme Optimized)

English | [中文](README-zh.md)

A highly optimized, automated build script for FFmpeg, supporting **Linux** and **macOS (Apple Silicon & Intel)**.

This project is a deeply refactored fork based on the work of [Martin Riedl](https://gitlab.com/martinr92) and [Hayden Zheng (MiKayule)](https://github.com/MiKayule). While previous versions introduced basic PGO/LTO optimizations, **this branch completely overhauls the build architecture** to achieve true cross-platform stability, introduces an advanced PGO training pipeline, adds new AI/audio components, and streamlines the CI/CD process.

## 📥 Pre-compiled Binaries

Don't want to build from source?
You can download the latest pre-compiled binaries for **Linux** and **macOS** from the **[GitHub Releases](https://github.com/MIKU552/ffmpeg-build-mika/releases)** page. These builds are automatically generated by our CI pipeline and are fully supercharged with PGO.

## 🎯 PGO Optimization Targets (The Secret Sauce)

Unlike standard builds, the encoders in this repository (`x265`, `SVT-AV1`, `VVenC`) are compiled using **Profile-Guided Optimization (PGO)** explicitly tailored for **extreme high-quality, slow-preset video encoding** (e.g., Anime, Archival, Movies).

During the build process, the compilers are fed with heavy workloads to optimize the deepest motion-search and block-partitioning C/Assembly branches. If your daily encoding commands match or resemble the following parameters, you will experience the absolute maximum performance these codecs can offer:

* **`x265` (HEVC) Target:**
```text
--preset veryslow --crf 28 --rc-lookahead 250 --open-gop

```


* **`SVT-AV1` (AV1) Target:**
```text
--preset 2 --lookahead 120 --tune 0

```


* **`VVenC` (VVC/H.266) Target:**
```text
--preset 3 -q 26

```



## ✨ Key Features & Deep Refactoring

* **📉 Advanced PGO Workflow**:
* Implemented a robust, cross-platform Profile-Guided Optimization pipeline. It intelligently handles parallel training on CI runners to generate highly accurate profiling data without hanging or crashing.
* Removed Git LFS dependencies for PGO training samples. Samples are now downloaded externally or skipped if missing, preventing Git LFS quota errors.


* **🔧 Cross-Platform Restoration**:
* Fixed build breakages on Linux caused by previous macOS-centric code.
* Unified entry point (`build_fix.sh`) that auto-detects the OS and applies the exact compiler flags, linker flags, and macro suppressions needed per platform.


* **⚡ Incremental Compilation (Hot Start)**:
* Implements a smart check: existing libraries in `tool/lib` are detected and skipped during re-runs. This allows for fast "hot starts" when debugging without recompiling the entire dependency tree.


* **🚀 Hardware Acceleration**:
* **Linux**: Added support for `VAAPI`, `Vulkan`, and `libdrm`.
* **macOS**: Retains `VideoToolbox` and `AudioToolbox` support.


* **📦 New Modern Components**:
* **Whisper**: Integrated `libwhisper` (Whisper.cpp) for AI hardware-accelerated speech-to-text.
* **FDK-AAC & Soxr**: Industry-standard, high-quality audio encoding and resampling.


* **🤖 Automated CI/CD**:
* Robust GitHub Actions workflow. Automatically compiles and releases binaries for both **macOS** and **Linux** concurrently.

## 🛠️ Build Instructions

### 1. Install Dependencies

Ensure your system has the necessary build tools installed.

**Linux (Debian / Ubuntu):**

*Requires Vulkan SDK for hardware acceleration support.*

```bash
# 1. Add LunarG Vulkan SDK Repository
wget -qO- https://packages.lunarg.com/lunarg-signing-key-pub.asc | sudo tee /etc/apt/trusted.gpg.d/lunarg.asc
sudo wget -qO /etc/apt/sources.list.d/lunarg-vulkan-noble.list http://packages.lunarg.com/vulkan/lunarg-vulkan-noble.list
sudo apt-get update

# 2. Install System Dependencies
sudo apt-get install -y --no-install-recommends \
    build-essential gcc g++ binutils make cmake ninja-build pkg-config \
    curl wget patch tar gzip bzip2 xz-utils zip python3 python3-pip \
    python3-venv python3-virtualenv nasm git-lfs docbook-utils \
    xsltproc asciidoc xmlto gperf autopoint automake libtool autoconf \
    gettext liblzma-dev libnuma-dev libssl-dev ccache \
    libva-dev libdrm-dev vulkan-sdk

# 3. Install Rust (Required for rav1e/svt-av1/cargo-c)
curl https://sh.rustup.rs -sSf | sh -s -- -y
source "$HOME/.cargo/env"
cargo install cargo-c --version 0.10.20 --locked

```

**macOS:**

```bash
brew update
brew install automake libtool cmake ninja nasm pkg-config ccache wget xz

# Install Rust
curl https://sh.rustup.rs -sSf | sh -s -- -y
source "$HOME/.cargo/env"
cargo install cargo-c --version 0.10.20 --locked

```

### 2. Compile

The script **does not** create a build directory automatically. You must create one to keep the source tree clean.

```bash
# 1. Clone the repository
git clone https://github.com/your-username/ffmpeg-build-mika.git
cd ffmpeg-build-mika

# 2. Create and enter the build directory
mkdir build
cd build

# 3. Run the build script (relative path to the script)
# Common flags:
# -SKIP_BUNDLE=NO: Packs the result into a .tar.gz (Linux) or .zip (macOS)
# -SKIP_TEST=YES: Skips the post-build test suite (saves time)
../build_fix.sh -SKIP_BUNDLE=NO -SKIP_TEST=YES

```

Due to the **Incremental Compilation** feature, if a library (e.g., `x264`) is found in `tool/lib`, the script will skip building it. To force a rebuild of specific components, delete the `build` directory or the specific artifacts in `tool/`.

### 3. Build Arguments

You can customize the build by passing arguments to `build_fix.sh`:

* **Optimization**:
* `-ENABLE_FFMPEG_PGO=YES`: Enables Profile-Guided Optimization for FFmpeg core itself. *(Note: Codecs like x265, SVT-AV1, and VVenC are heavily PGO-optimized by default during their own specific build steps).*


* **Feature Toggles**:
* `-SKIP_WHISPER=YES`: Skip building the Whisper AI model.
* `-SKIP_DECKLINK=NO`: Enable Blackmagic Decklink support (requires you to provide the SDK path via `-DECKLINK_SDK=...`).
* `-SKIP_VVENC=YES`: Skip the VVC encoder.


* **Versioning**:
* `-FFMPEG_SNAPSHOT=NO`: Build a specific release version defined in `version/ffmpeg` instead of the latest master snapshot.



## 📂 Output

After a successful build, the `out` directory (inside your `build` folder) will contain:

* `bin/` : Executables (`ffmpeg`, `ffplay`, `ffprobe`, `vvencapp`, etc.).
* `lib/` : Shared/Static libraries.
* `include/` : Headers.
* `ffmpeg-build-*.tar.gz` (Linux) or `*.zip` (macOS).

> **Note for macOS**: The script automatically handles dylib relocation (`@executable_path`). The generated zip file is fully portable and can be run from any directory after extraction.
